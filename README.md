# NEVTEK — simple startup landing page

A responsive, static landing page for the early-stage NEVTEK AI study assistant concept.

## Preview locally
Open `index.html` in a modern browser.

## Publish free with GitHub Pages
1. Create a new public GitHub repository named `nevtek-site`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish and use the URL shown in Settings → Pages.

Alternatively, import the repository into Vercel and deploy it as a static site.

## Important
This is a landing page only, not the full AI application. It does not process documents or call AI APIs. It accurately describes NEVTEK as an early-stage concept. A website alone does not guarantee cloud credits or startup-program approval.
